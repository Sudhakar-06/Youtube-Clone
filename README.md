# YouTube Clone

A responsive recreation of the YouTube interface, built from scratch with HTML, CSS and JavaScript. It works on phones, tablets and desktops.

> Status: in progress. I'm building it day by day and committing daily.

## Preview

Screenshots coming soon.

## Goals

- Match YouTube's real layout and design as closely as possible
- Fully responsive (mobile-first)
- Clean, semantic, well-organized code
- Real videos and search using the YouTube Data API (planned)

## Built With

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, custom properties, media queries)
- JavaScript (coming soon)

## Planned Features

- [✓] Header with search bar
- [ ] Sidebar navigation
- [ ] Responsive video grid
- [ ] Dark mode
- [ ] Real search with the YouTube Data API
- [ ] Video playback page
